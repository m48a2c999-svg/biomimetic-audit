# 판정 기준표(코드북) — 생체모방 건축 외피 연구의 주장 판정

판정 단위: 건축 외피(파사드·외피·차양·외피 재료)에 생체모방을 적용했다고 주장하는 개별 연구 1편.
판정 자료: 제목·초록·주제어(193편 전수), 공개 접근 원문 발췌(18편).

## 1. 선별 기준
- 포함 I1 생체모방(biomimetic, biomimicry, bio-inspired, nature-inspired, bionic 등)을 자기 연구의 성격으로 내세운다.
- 포함 I2 대상이 건물 외피(외벽·파사드·차양·지붕 외피·외피 재료·외피 제어)이다.
- 포함 I3 학술지 논문·학술대회 논문·단행본 장이며 초록이 있다.
- 제외 E1 생체모방이 배경 언급에 그치거나 대상이 외피가 아니다(구조 일반, 도시계획, 실내, 의공학 등).
- 제외 E2 영어 초록이 아니다.
- 제외 X 중복 출판.
- 별도 N 제목상 적격이나 초록이 없다(판정하지 않고 시기 분포만 비교).
- 별도 R 리뷰·개관 논문은 판정 대상에서 빼고 담론 참고 자료로 둔다.

## 2. 판정 항목

|---|---|---|---|
| B1 | 생물 모델 명시 | 0 없음 / 1 있음 | 특정 생물·생물 체계(종·기관·조직)를 이름으로 밝히면 1. "자연", "생물"만 쓰면 0 |
| B2 | 생물 기능·기제 기술 | 0 이름만 / 1 기능 / 2 기제 | 2는 생물 쪽의 작동 기제(예: 이중층 흡습 변형, 공변세포 팽압)를 서술한 경우 |
| T1 | 전이 절차 명시 | 0 / 1 | 추상화·전이 단계, ISO 18458, 하향식·상향식, BioTRIZ, 설계 나선 등 절차를 밝히면 1 |

| P | 생물학 소속 저자 | 0 / 1 | OpenAlex 저자 소속 원문에 biology, botany, zoology, plant science, life sciences, ecology 등이 있으면 1 |

## 3. 판정 절차
1. 사전어 규칙(audit/code_rules.py)으로 전수 자동 판정을 먼저 시도하였다.
2. 층화 무작위 표본 119편을 초록 정독으로 판정해 자동 판정과 비교하였다(audit/agreement.json). 생물 명시(κ=0.16), 모방 수준(κ=0.17) 등의 일치도가 낮고 R=3을 찾지 못해, 자동 판정은 결과로 쓰지 않았다.
3. 판정 대상 193편 전체를 초록 정독으로 판정하였다(audit/manual_codes_all.json). 판정자는 1인이다. 표본 119편과 나머지 74편의 두 차례 판정 사이에 기준 차이가 확인되어, 이 표의 규칙으로 193편 전체의 정량 성능·비교 기준·생물 명시를 재점검하였다(수정 내역 audit/recheck_log.json, 수정 전 audit/manual_codes_before_recheck.json).
4. 공개 접근 원문을 확보한 18편은 원문 발췌로 다시 판정하였다(audit/fulltext_codes.json, audit/fulltext_compare.json).
5. 근거 수준(누적): 0 = B1=0 또는 B2=0, 1 = B1=1·B2≥1, 2 = 1+T1=1, 3 = 2+E≥2·Q=1, 4 = 3+R=3.

## 4. 해석 원칙
- 초록에 없다는 것은 원문에 없다는 뜻이 아니다. 초록 판정은 "연구가 스스로 앞세운 주장과 근거"의 지표이며, 원문 표본으로 그 차이를 함께 보고한다.
- R=3(같은 기능의 비생체모방 대안과 비교)만이 "생체모방이라서 낫다"는 주장을 시험할 수 있는 설계이다. R=1·2는 장치의 효과를 보일 뿐 생체모방의 기여를 보이지 않는다.
