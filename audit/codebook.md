# 판정 기준표(코드북) — 생체모방 건축 외피 연구의 주장 판정

판정 단위: 건축 외피(파사드·외피·차양·외피 재료)에 생체모방을 적용했다고 주장하는 개별 연구 1편.
판정 자료: 제목·초록·주제어(전수), 공개 접근 원문 발췌(표본).

## 1. 선별 기준
- 포함 I1 생체모방(biomimetic, biomimicry, bio-inspired, nature-inspired, bionic 등)을 자기 연구의 성격으로 내세운다.
- 포함 I2 대상이 건물 외피(외벽·파사드·차양·지붕 외피·외피 재료·외피 제어)이다.
- 포함 I3 학술지 논문·학술대회 논문·단행본 장이며 초록이 있다.
- 제외 E1 생체모방이 배경 언급에 그치거나 대상이 외피가 아니다(구조 일반, 도시계획, 실내, 의공학 등).
- 제외 E2 초록이 없거나 영어 초록이 아니다.
- 구분 R 리뷰·개관 논문은 "리뷰 집단"으로 따로 두고 담론 항목(S1)만 판정한다.

## 2. 판정 항목

| 기호 | 항목 | 수준 | 판정 규칙 |
|---|---|---|---|
| B1 | 생물 모델 명시 | 0 없음 / 1 있음 | 특정 생물·생물 체계(종·기관·조직)를 이름으로 밝히면 1. "자연", "생물"만 쓰면 0 |
| B2 | 생물 기능·기제 기술 | 0 이름만 / 1 기능 / 2 기제 | 2는 생물 쪽의 작동 기제(예: 이중층 흡습 변형, 공변세포 팽압)를 서술한 경우 |
| T1 | 전이 절차 명시 | 0 / 1 | 추상화·전이 단계, ISO 18458, 하향식·상향식, BioTRIZ, 설계 나선 등 절차를 밝히면 1 |
| L | 모방 수준 | 형태 / 구조·재료 / 과정·행동 / 생태계 / 불명 | 무엇을 옮겼는가. 제어·작동 규칙은 과정·행동 |
| E | 근거 유형(최고 수준) | 0 개념·제안 / 1 설계안·정성 / 2 시뮬레이션 / 3 시제품·실험 / 4 실건물 측정 | 초록에 적힌 방법 중 가장 높은 수준 |
| Q | 정량 성능 보고 | 0 / 1 | 초록에 성능 수치(%, kWh, °C, lx 등)가 있으면 1 |
| R | 비교 기준 | 0 없음 / 1 기준안 / 2 정적 일반 장치 / 3 같은 기능의 비생체모방 대안 | 1은 장치 없음·개보수 전·기존 외피, 2는 고정 차양·일반 블라인드 등, 3은 같은 기능을 하는 일반 동적 장치나 일반 제어 |
| S1 | 지속가능성 주장 | 0 / 1 | sustainable, eco-friendly, green, environmentally friendly 등으로 성과를 규정하면 1 |
| S2 | 지속가능성 근거 | 0 없음 / 1 운영 에너지만 / 2 전과정(LCA·내재 탄소·비용) | S1=1인 연구에서 판정 |
| P | 생물학 소속 저자 | 0 / 1 | OpenAlex 저자 소속 원문에 biology, botany, zoology, plant science, life sciences, ecology 등이 있으면 1 |

## 3. 판정 절차
1. 1차: 사전어 규칙(부록 B의 정규식)으로 전수 자동 판정.
2. 2차: 층화 무작위 표본(연도 구간 × 근거 유형)을 초록 정독으로 판정.
3. 일치도: 항목별 Cohen의 카파와 일치율. 정독 판정을 기준으로 자동 판정의 민감도·특이도를 구하고, 전수 비율은 오분류를 보정한 값(Rogan–Gladen 추정)과 함께 보고.
4. 원문 표본: 공개 접근 원문이 있는 연구 중 피인용 상위와 무작위 표본에서 B2·T1·R·S2를 원문 발췌로 재판정해 초록 판정의 과소·과대를 확인.

## 4. 해석 원칙
- 초록에 없다는 것은 원문에 없다는 뜻이 아니다. 초록 판정은 "연구가 스스로 앞세운 주장과 근거"의 지표이며, 원문 표본으로 그 차이를 함께 보고한다.
- R=3(같은 기능의 비생체모방 대안과 비교)만이 "생체모방이라서 낫다"는 주장을 시험할 수 있는 설계이다. R=1·2는 장치의 효과를 보일 뿐 생체모방의 기여를 보이지 않는다.
